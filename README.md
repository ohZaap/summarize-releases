# Summarize — releases

Instaladores do **Summarize**, gravador, transcritor e resumidor de reuniões que roda localmente (Windows e Linux).

Baixe a versão mais recente em [Releases](../../releases/latest):

- **Windows**: `Summarize_x.y.z_x64-setup.exe` (recomendado) ou `.msi`
- **Linux**: `.AppImage` ou `.deb`

O app instalado verifica este repositório e se atualiza sozinho (`latest.json`, assinado).
O código-fonte fica em um repositório privado; este repositório contém apenas os binários publicados.
